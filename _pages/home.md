# Hey everyone

My name is Venom and welcome to my personal website! There really isn't a whole lot to see here currently, but as time goes on, this page (and blog) will be more and more fleshed out and have proper content/updates to read up on.

**There will likely be a LOT of leftover artifacts from the template I'm using,** so if you find a page or section that may deviate from the normal content, please raise an issue in the GitHub page for this website (bonus points for finding the location in the source <3).

## Website Goals (roadmap section soon™)

The goal of this website is as follows:

- [ ] Get it to a mostly polished state and share it with anyone whos interested
- [ ] Develop a portfolio and host an up-to-date resume
- [ ] Post personal project progress, guides, and discoveries
- [ ] Create a digital gallery of my projects for funsies
- [ ] Supplement building a community with other socials (ie. YouTube, Twitch, GitHub, etc.)
- [ ] Learn how this newfangled "Jekyll" technology works to update the [hackerspace website](https://hhacker.space)

You can start by looking in the ["Posts"](/posts) section for anything new there, or as mentioned before, report bugs or make suggestions by creating an issue in the [website's GH repository](https://github.com/venomboss985/venomboss985.github.io). Thank you for your time!
